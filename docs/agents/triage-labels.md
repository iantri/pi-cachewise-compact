# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting for information from the reporter |
| ready-for-agent | ready-for-agent | Fully specified; ready for an unattended agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

When a skill names a triage role, use its tracker label from this table.
Edit the tracker-label column if the repository’s vocabulary changes.
